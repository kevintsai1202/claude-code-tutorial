# 🛒 購物車系統 — 作品說明

---

## 一句話描述

> **一個讓使用者瀏覽商品、管理購物車、填寫結帳資料的前後端系統。**

---

## 系統範圍（刻意精簡）

✅ **包含**
- 商品瀏覽（列表、分類篩選、搜尋、詳情頁）
- 購物車管理（加入、移除、修改數量、清空）
- 購物車小計 / 總計即時計算
- 結帳表單（填收件資訊）→ 送出視為完成

❌ **不包含**（刻意省略，避免課程複雜度過高）
- 庫存扣減邏輯
- 訂單狀態機（PAID / SHIPPED / DELIVERED）
- 付款金流整合

## 核心實體

```
Product（商品）
├── id, name, description
├── price
├── category        ← 3C / 服飾 / 食品
├── imageUrl
└── rating          ← 評分 1~5（測試資料帶入）

Cart（購物車）
├── id
├── sessionId       ← 未登入用 session；登入用 userId
└── items[]         ← CartItem 清單

CartItem（購物車明細）
├── cart
├── product
└── quantity        ← 最多 99 件

CheckoutRequest（結帳表單）
├── name, email, phone, address
└── cartId
```

---

## 業務規則（簡化後）

```
加入購物車：
  同一商品再次加入 → 數量 +1（不重複新增）
  數量上限 99 件

修改數量：
  quantity = 0 → 自動移除此 CartItem

購物車計算：
  小計 = Σ (item.quantity × item.product.price)
  伺服器計算，不接受客戶端傳入

結帳送出：
  驗證收件資料不為空
  送出成功 → 清空購物車 → 回傳確認訊息
  （不做庫存扣減、不產生訂單記錄）
```

## API 端點

```
# 商品
GET    /api/products              ← 列表（?category=3C&search=手機&page=0）
GET    /api/products/{id}         ← 詳情

# 購物車
GET    /api/cart                  ← 取得目前購物車（含 items + 小計）
POST   /api/cart/items            ← 加入商品（同商品自動合併數量）
PUT    /api/cart/items/{itemId}   ← 修改數量（quantity=0 自動移除）
DELETE /api/cart/items/{itemId}   ← 移除商品
DELETE /api/cart                  ← 清空購物車

# 結帳
POST   /api/cart/checkout         ← 送出結帳資料 → 清空購物車
```
